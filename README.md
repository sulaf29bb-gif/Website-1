# TuneTech: RIG-444 Calibration Rig (Bachelor's Project 2026)

Website for **RIG-444**, a bachelor's project at USN in cooperation. The project is developing a mostly automated, versatile calibration rig for sensors in Kongsberg Automotive's in-house laboratory.

## About this repository

A static website made with plain HTML and CSS (no build step needed). Designed with Figma.
.
├── index.html     # main page
├── index.css      # styles for the main page
├── style.css      # shared base styles
├── 404.html       # "page not found" page
├── 404.css        # styles for the 404 page
├── public/        # images and logos
└── locales/       # translation files (currently unused)
