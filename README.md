# TuneTech: RIG-444 Calibration Rig (Bachelor's Project 2026)

Website for **RIG-444**, a bachelor's project at USN in cooperation with Kongsberg Automotive. The project is developing a mostly automated, versatile calibration rig for sensors in Kongsberg Automotive's in-house laboratory.
